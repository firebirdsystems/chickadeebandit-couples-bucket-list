# Couple's Bucket List

A [Chickadee Bandit](https://chickadeebandit.com/app-library/couples-bucket-list) app.

A shared wishlist of experiences — travel, food, skills, milestones — that you want to do together.

## Features

- Either partner adds items.
- Categories: travel, food, skills, milestones, anything.
- Complete with a reflection note and optional photo.
- Private to the two of you. Adults only.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-couples-bucket-list/releases/latest/download/bundle.json
```
